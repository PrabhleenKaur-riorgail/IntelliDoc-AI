# IntelliDoc AI: Intelligent Document Processing & Responsible AI Compliance Analyzer

A full-stack AI application aligned with **Microsoft Azure AI Fundamentals (AI-901)** exam domains:
1. **Azure AI Document Intelligence**: Automated OCR, key-value pair extraction, and line-item parsing.
2. **Azure AI Language (NLP)**: Language detection, sentiment analysis with confidence scores, key phrase extraction, and Named Entity Recognition (NER).
3. **Azure AI Content Safety & Responsible AI**: Multi-category harm severity scoring (Hate, Violence, Self-Harm, Sexual) and automated PII detection/masking.
4. **Azure OpenAI / Microsoft Foundry (GenAI)**: Grounded Retrieval-Augmented Generation (RAG) Q&A over uploaded documents.

## One-Click Start
- **Windows**: Double-click `run_windows.bat`
- **Mac/Linux**: Run `bash run_mac_linux.sh` in terminal

## Manual Start
```bash
pip install -r requirements.txt
streamlit run app.py
```
